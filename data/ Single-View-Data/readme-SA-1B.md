# SA-1B Dataset (Segment Anything 1-Billion)

## Overview

**SA-1B (Segment Anything 1-Billion)** is the **largest segmentation dataset ever created**, introduced as part of the **Segment Anything Model (SAM)** project by **Meta AI Research, FAIR** in 2023. It contains **11 million images** with over **1.1 billion segmentation masks**, making it approximately **400× larger** than any existing segmentation dataset. The dataset was built using a model-in-the-loop data engine that iteratively improved both the model and the data annotations.

- **Paper**: [Segment Anything](https://arxiv.org/abs/2304.02643) (ICCV 2023)
- **Source Repository**: [https://github.com/facebookresearch/segment-anything](https://github.com/facebookresearch/segment-anything)
- **Dataset Page**: [https://segment-anything.com/dataset/index.html](https://segment-anything.com/dataset/index.html)
- **Project Page**: [https://segment-anything.com/](https://segment-anything.com/)
- **License**: SA-1B Dataset Research License (custom; model is Apache 2.0)

## Dataset Description

SA-1B was created using SAM's data engine, which consists of three stages: (1) assisted-manual annotation, (2) semi-automatic annotation with model-predicted masks, and (3) fully automatic mask generation at scale. The dataset spans a wide variety of images licensed from a large-scale photo provider, covering diverse objects, scenes, and geographies.

The masks are generated automatically by SAM and are of high quality, with each mask accompanied by:
- The model's own **predicted IoU** score (quality estimation)
- A **stability score** (robustness measure)
- The **bounding box** and **point prompts** used to generate the mask

### Key Statistics

| Property | Value |
|---|---|
| Total Images | ~11 million |
| Total Masks | ~1.1 billion |
| Average Masks per Image | ~100 |
| Mask Format | COCO RLE (Run-Length Encoding) |
| Image Resolution | ~1500 pixels on average (shortest side) |
| Dataset Size | ~4.5 TB (compressed) |

## Data Format

Masks are saved per image as JSON files. Each JSON file can be loaded as a dictionary with the following structure:

```json
{
  "image": {
    "image_id": 123456,
    "width": 1500,
    "height": 1000,
    "file_name": "sa_123456.jpg"
  },
  "annotations": [
    {
      "id": 1,
      "segmentation": { ... },        // Mask in COCO RLE format
      "bbox": [x, y, w, h],          // Bounding box in XYWH format
      "area": 98765,                  // Area in pixels
      "predicted_iou": 0.95,          // Model's quality prediction
      "stability_score": 0.92,        // Mask quality measure
      "crop_box": [x, y, w, h],      // Crop used to generate the mask
      "point_coords": [[x, y]]        // Point prompt coordinates
    },
    ...
  ]
}
```

### Decoding Masks

To decode a mask from COCO RLE format into a binary mask:

```python
from pycocotools import mask as mask_utils
mask = mask_utils.decode(annotation["segmentation"])
```

## Key Features

- **Largest segmentation dataset ever**: 1.1 billion masks, 400× larger than prior datasets.
- **Fully automatic annotations**: Masks generated by SAM's data engine, not manual annotation.
- **Quality-aware**: Each mask includes predicted IoU and stability scores for filtering.
- **Prompt-based**: Each mask is associated with the point prompts that generated it.
- **Diverse coverage**: 11 million images covering a wide range of objects and scenes.
- **Zero-shot enabler**: SAM trained on SA-1B achieves strong zero-shot performance on many segmentation tasks.
- **Foundation model dataset**: Supports the development of general-purpose, promptable image segmentation models.

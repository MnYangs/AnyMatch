# AnyMatch Fine-Tuned Model Weights

This repository provides the weights of three feature matching networks — **EDM**, **LoFTR**, and **RoMa** — fine-tuned using the **AnyMatch** framework. After fine-tuning on the AnyMatch synthetic dataset (Any-syn), these models achieve substantial performance gains on cross-modal image matching tasks, demonstrating superior generalization and robustness.
